# Getting Started with bx-sites

The fastest way to learn bx-sites end to end - twenty short lessons, in
order, each building on the last. Every lesson is short on purpose, with
a link out to the full guide wherever a topic goes deeper than a lesson
can cover.

Your progress through the course - which lessons you've read, and where
to pick back up - is remembered right in this browser as you go.
