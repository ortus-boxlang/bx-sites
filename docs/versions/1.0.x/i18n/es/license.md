## Dependencias de terceros

BxSites depende de un puñado de otros módulos de BoxLang -
[bx-markdown](https://github.com/ortus-boxlang/bx-markdown),
[bx-esapi](https://github.com/ortus-boxlang/bx-esapi),
[bx-yaml](https://github.com/ortus-boxlang/bx-yaml), y
[bx-image](https://github.com/ortus-boxlang/bx-image) - junto con las
bibliotecas del lado del cliente que cada tema integrado incluye
(Bootstrap, highlight.js, Alpine.js, lunr.js, y opcionalmente Mermaid).
Cada una tiene su propia licencia de código abierto; consulta el
repositorio de cada proyecto para más detalles.
