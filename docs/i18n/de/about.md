# Über das Projekt

BxSites ist ein universeller **Static-Site-Generator**, geschrieben in
[BoxLang](https://boxlang.io) - richte es auf einen `docs/`-Ordner und
erhalte eine themenfähige, durchsuchbare statische Website, mit demselben
Toolkit egal ob du Referenzdokumentation, einen Blog, eine
Marketing-Website oder eine Wissensdatenbank baust. Es basiert auf
[bx-markdown](https://github.com/ortus-boxlang/bx-markdown), im Geiste von
[mkdocs](https://www.mkdocs.org/), und genau diese Website wird von
BxSites selbst gebaut, aus den Markdown-Dateien in ihrem eigenen
`docs/`-Ordner.

## Wer es entwickelt

BxSites wird von [Ortus Solutions, Corp](https://www.ortussolutions.com)
gebaut und gepflegt, den Machern von [BoxLang](https://boxlang.io),
[ColdBox](https://coldbox.ortusbooks.com/),
[CommandBox](https://commandbox.ortusbooks.com/) und dem Rest des
BoxLang-Ökosystems - demselben Team, das auch die Runtime baut, auf der
BxSites selbst läuft.
