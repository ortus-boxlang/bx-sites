# Acerca de

BxSites es un generador de sitios estáticos **de propósito general**,
escrito en [BoxLang](https://boxlang.io) - apúntalo a una carpeta `docs/` y
obtén un sitio estático con temas y búsqueda integrada, con el mismo kit de
herramientas ya sea que estés construyendo documentación de referencia, un
blog, un sitio de marketing o una base de conocimiento. Está construido
sobre [bx-markdown](https://github.com/ortus-boxlang/bx-markdown), en el
espíritu de [mkdocs](https://www.mkdocs.org/), y este mismo sitio está
construido por BxSites, a partir de los archivos Markdown de su propia
carpeta `docs/`.

## Quién lo desarrolla

BxSites es desarrollado y mantenido por
[Ortus Solutions, Corp](https://www.ortussolutions.com), los creadores de
[BoxLang](https://boxlang.io), [ColdBox](https://coldbox.ortusbooks.com/),
[CommandBox](https://commandbox.ortusbooks.com/) y el resto del
ecosistema BoxLang - el mismo equipo que construye el runtime sobre el
que corre BxSites.
